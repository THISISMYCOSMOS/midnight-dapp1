# 영지식 증명과 미드나잇 — 입문 영상 (약 3분)

처음 접하는 사람을 위한 설명 영상. 한국어 더빙 + 화면 자막.
코드로 만드는 영상이다: 대본(`script.json`)을 고치고 두 명령을 다시 돌리면 영상이 다시 나온다.

## 구성 (8장면, 34문장)

| # | 장면 | 쓰는 예시 |
|---|---|---|
| 01 | 질문 | 비밀번호를 보여주지 않고 안다는 걸 증명할 수 있을까 |
| 02 | 일상의 예 | 편의점 신분증 — 필요한 정보 1개, 보여주는 정보 4개 |
| 03 | 월리를 찾아라 | 그림보다 큰 종이 + 작은 구멍 |
| 04 | 영지식 증명 | 참이면 통과 / 거짓이면 못 속임 / 비밀은 안 샘 |
| 05 | 블록체인의 고민 | 모두가 보는 유리 장부 |
| 06 | 미드나잇 | 내 컴퓨터(비밀) → 증명 → 공개 장부. Compact 코드 3줄 |
| 07 | 익명 후기 게시판 | 이 저장소의 DApp: 도장(파생키)·머클 트리·상품별 도장(nullifier) |
| 08 | 정리 | 증명은 공개, 비밀은 내 손. 한계 2개 |

07의 설명은 `contract/src/review.compact`와 대응한다. 도장 = `deriveReviewerKey`,
상품별 두 번째 도장 = `deriveNullifier`, 뿌리 값 = `eligible` MerkleTree 루트.
자격 명단(도장 목록)은 공개이므로 영상도 "도장은 보이지만 누구 것인지 모른다"로 말한다.
수수료 지갑에 의한 연결은 범위 밖이라는 캐비엇(AGENTS.md §1)을 08에 넣었다.

## 도구

| 역할 | 도구 | 이유 |
|---|---|---|
| 화면 | `scenes.html` (HTML/SVG, 시간 `t`를 받아 그리는 함수) | 도식·자막을 정확한 위치와 타이밍으로 그릴 수 있고 텍스트 수정이 쉽다 |
| 캡처 | Playwright + Chromium, 프레임 단위 | 실시간 녹화가 아니라 프레임마다 찍어서 끊김이 없다 |
| 인코딩 | ffmpeg (`imageio-ffmpeg`) · H.264 + AAC | 어디서나 재생 |
| 더빙 | sherpa-onnx + `vits-mimic3-ko_KO-kss_low` (오프라인 한국어 TTS) | 이 클라우드 환경에서 외부 음성 서버가 막혀 있어 로컬 모델 사용 |
| 검증 | SenseVoice 음성인식으로 합성 음성을 되받아 적기 | 들을 수 없는 환경에서 발음을 수치로 확인 |

## 만들기

```bash
./setup.sh                 # 모델·폰트·패키지 (최초 1회)
python3 build_audio.py     # out/narration.wav, timeline.json, subtitles.srt, asr-check.txt
python3 render.py          # out/zk-midnight-intro.mp4 (1920×1080, 30fps)
python3 render.py --stills 12 45 140   # 특정 시점 정지 화면만 (검수용)
```

`build_audio.py`를 다시 돌리면 합성 음성이 미세하게 달라져 타이밍이 바뀐다.
그 경우 `render.py`도 다시 돌린다. 기존 음성을 유지하려면 `--reuse`.

## 목소리 바꾸기

합성 음성은 사람 목소리보다 확실히 부자연스럽다. 발표에 쓰려면 교체를 권한다.

- **직접 녹음**: `out/lines/<장면id>-<번호>.wav`(22050Hz 모노)를 같은 이름으로 덮어쓰고
  `python3 build_audio.py --reuse && python3 render.py`. 문장 길이가 바뀌어도 화면 타이밍이 따라간다
- **다른 TTS**: 문장별 wav만 만들면 위와 같은 방법으로 들어간다

발음이 뭉개지는 단어는 `script.json`의 `say`에 소리 나는 대로 적는다
(예: "영지식 증명" → `"영 지식 쯩명"`). 화면 자막은 `text`가 그대로 나간다.
